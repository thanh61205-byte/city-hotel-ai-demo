# Local demo state

G2 creates its SQLite action log here. These files contain local demo history and are excluded from Git. Keep an existing database if you want to retain its history; use `G2_DB_PATH` to start a separate demo.

Current model outputs live in `artifacts/modeling/`, and G1 policy outputs in `artifacts/business_case/`. See [the demo guide](../../RUN_DEMO.md) for setup and reset instructions.
